# Portfolio

A personal portfolio website built with **React** and **Next.js**, with a downloadable ATS-friendly CV generated from the same data as the site.

**Live site:** https://rzhuka.github.io/portfolio/

## Tech stack

- Next.js 14 (App Router, static export) and React 18
- TypeScript (strict mode)
- SCSS with BEM class names
- Framer Motion for animations
- pdfkit for PDF generation
- Jest and React Testing Library
- ESLint and Prettier
- GitHub Actions and GitHub Pages

## Features

- Animated hero with letter-by-letter reveal, cursor spotlight and parallax
- Floating navigation that highlights the active section
- Scroll progress bar, cursor glow and scroll-reveal animations
- Technology marquee, project cards and an experience timeline
- Downloadable ATS-friendly CV (PDF), generated at build time
- Responsive layout, keyboard-accessible, and respects `prefers-reduced-motion`

## Getting started

Requirements: Node.js 20 or newer.

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Scripts

| Command             | Description                                         |
| ------------------- | --------------------------------------------------- |
| `npm run dev`       | Generate the CV and start the development server    |
| `npm run build`     | Generate the CV and build the static site to `out/` |
| `npm run lint`      | Run ESLint                                          |
| `npm run typecheck` | Type-check the project with TypeScript              |
| `npm test`          | Run the test suite                                  |
| `npm run format`    | Format the code with Prettier                       |
| `npm run cv`        | Regenerate `public/cv.pdf` only                     |

## Content

All content (personal details, experience, education, skills and projects) lives in a single typed file, `src/data/profile.ts`. The website and the CV PDF are both generated from it, so they always stay in sync.

## Architecture

```
src/
  app/                  Next.js layout and page
  components/           Atomic Design
    atoms/              Button, Chip, Reveal, SectionTitle
    molecules/          Section, TimelineEntry, ProjectItem, SkillGroup
    organisms/          Header, Hero, ProjectList, page sections, Footer,
                        ScrollProgress, CursorGlow, TechMarquee
    templates/          HomeTemplate (page composition)
  features/cv/          CV model (data to document) and PDF renderer
  data/profile.ts       Single source of truth
  types/                Domain types
  styles/               SCSS: abstracts (variables, mixins), base,
                        one partial per component, main.scss entry
  config/ lib/ hooks/   Site constants, utilities, reusable hooks
scripts/generate-cv.ts  Writes public/cv.pdf at build time
```

Conventions:

- Data flows top-down through props; `HomeTemplate` composes the page.
- Only components that need browser APIs or animation are client components.
- Styling uses SCSS partials with BEM naming (for example `hero__name`, `btn--solid`). Design tokens are CSS variables in `src/styles/base/_root.scss`.
- Imports use the `@/` alias, with a barrel file per layer.

## ATS-friendly CV

`public/cv.pdf` is generated by `scripts/generate-cv.ts`. It is a single-column PDF with real, selectable text, standard section headings (Summary, Skills, Experience, Projects, Education), a built-in font and plain bullets, with no images, icons or tables, so applicant tracking systems can parse it reliably.

## Deployment

The workflow in `.github/workflows/deploy.yml` runs on every push to `main`:

1. **quality**: lint, type-check and tests (also runs on pull requests)
2. **build**: static export with the correct base path
3. **deploy**: publishes the `out/` folder to GitHub Pages

To deploy a fork or your own copy, push it to a public GitHub repository, then open **Settings → Pages** and set **Source** to **GitHub Actions**.
